AI-Helper

Черновик карточки прибора по вашим данным. Перед публикацией проверьте текст и характеристики.

Данные товара

Например: {"диапазон измерений": "0–1,6 МПа"}. Пустое значение будет отмечено как «данных нет».
Название и производитель будут отправлены в поиск DeepSeek. Поиск может оплачиваться отдельно; найденные сведения нужно проверить.

Данные, отправленные модели

JSON товара после проверки и, если поиск включён, найденные выдержки. Системные инструкции передаются модели отдельно.

Появятся после создания черновика.
